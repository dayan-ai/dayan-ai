### 💫 About me

I'm a **BS Data Science student at the Institute of Data Sciences, UET Lahore**. I build automation and LLM-backed workflows, and I spend most of my other hours getting students into rooms where they learn things.

- 🔭 **Currently building:** AI agents and n8n automation pipelines for B2B clients at **Xiomics Systems**
- 🎤 **Currently organizing:** outreach and PR for **AWS Student Builder Group – UET Lahore** and **PALS UET**
- 🌱 **Currently learning:** data structures, agent architectures, and how to write a README someone actually reads
- 💬 **Ask me about:** Python, SQL, n8n, the Claude API, or how to get 200 students to show up to a workshop
- 🤝 **Open to collaborating on:** open-source data projects, automation tooling, and campus tech events
